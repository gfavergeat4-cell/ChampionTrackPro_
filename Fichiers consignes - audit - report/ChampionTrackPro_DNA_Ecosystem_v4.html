⚠️ Critical Gaps Identified by Code Analysis
HIGH
Admin Tabs route to placeholder
AdminTabs "Teams" and "Analytics" tabs both render StitchAdminDashboard.js — a blank placeholder. Real AdminTeamDetailScreen is unreachable from the tab bar.
HIGH
V3 worryFlag not surfaced in coach alerts
CoachHomeScreen and CoachTeamScreen detect pain via V1 fields (impactMusculaire ≥ 70, fatigue ≥ 80). worryFlag from V3 Friction Matrix is never checked.
HIGH
Questionnaire params fragile
AthleteHome passes trainingId but StitchQuestionnaireScreen reads sessionId. Works because navigator also passes deprecated alias — but one refactor will silently break the questionnaire.
MEDIUM
AthleteDetailScreen uses V2 metric keys
Reads cardioLoad, motorControl (V2 names). V3 responses use tankLevel, legBounce. Mixed responses may silently show 0/null for newer athletes.
MEDIUM
Coach schedule uses V1 response field
CoachScheduleScreen detects physicalPain (V1 field) to color session cards. V3 responses never set this field — all sessions appear without pain indicator regardless of data.
LOW
Coach profile phone never saved
CoachProfileScreen shows a phone number input field in edit mode, but the phone field is absent from the handleSave() payload — user input silently discarded.
